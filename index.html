제주담다 팀 프로젝트

2025.08.10 - 09.25

overview

'제주담다'는 제주 여행 시 흩어진 정보를 찾기 위해 여러 사이트를 오가야 하는 불편함을 해결하고자 기획된 통합형 홈페이지입니다. 제주의 자연, 문화, 즐길 거리, 맛집을 한 곳에 모아 영상, 이미지, 검색 기능으로 직관적이고 차별화된 여행 정보를 제공합니다.
1개월간 팀으로 진행한 프로젝트며 메인화면과 '맛을담다' 페이지를 디자인하고 메인 코딩했습니다.

skill & Detail

figma / PremierePro / HTML5+CSS3+javascript(jQuery)+AOS+Swiper.js
메인 페이지는 비디오를 활용한 애니메이션을 중심으로 코딩했습니다. 첫 화면에서는 단순한 이미지 대신 실제 제주 영상을 편집해 배경으로 사용해 몰입감을 높였습니다. 서브페이지로 연결되는 소개 페이지에서는 마우스를 호버하면 해당 영역만 확대되는 인터랙션을 적용해 사용자의 시선을 자연스럽게 유도했습니다. 전체 슬라이드는 Swiper.js를 활용해 구현했습니다.
